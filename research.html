Generative-Enhanced Ensemble Framework for Diabetic Retinopathy Grading under Severe Class Imbalance

Ongoing
ELITE Research Lab LLC, New York

Developed a dual-head architecture combining ordinal regression with categorical classification for seven-stage diabetic retinopathy grading. The framework utilizes Stable Diffusion 2.1 generative augmentation with ControlNet-Canny conditioning and morphological attention masks for addressing severe class imbalance in medical imaging datasets.

Key Contributions:

  • Designed dual-head neural architecture integrating ordinal regression and categorical classification
  • Achieved 91.65% accuracy for seven-stage diabetic retinopathy classification
  • Implemented stacking ensemble combining five CNN architectures improving baseline accuracy by 2.09%
  • Applied explainable AI techniques using Grad-CAM++ for model interpretability and clinical validation
  • Achieved 91.67% macro F1-score demonstrating robust performance across imbalanced classes

Attentive TabNet Framework for Multiclass Intrusion Detection in IoMT

Manuscript in Preparation
Rangamati Science and Technology University
Bachelor's Thesis

Developed an advanced intrusion detection system for Internet of Medical Things (IoMT) environments using TabNet architecture with attention mechanisms. The framework incorporates GAN-based synthetic data generation to address class imbalance challenges in cybersecurity applications.

Key Contributions:

  • Designed attentive TabNet framework for multiclass intrusion detection in IoMT, overcoming limitations of binary-focused IDS systems
  • Addressed severe data imbalance through GAN-based synthetic minority sample generation
  • Demonstrated TabNet's attention mechanism superiority for generalizable IoMT security models
  • Achieved 97.96% multiclass accuracy across 89 million network traffic records
  • Validated framework performance on large-scale real-world IoMT datasets

A Deep Learning-Based Framework for Bangla Vehicle License Plate Detection and Recognition

Completed
Rangamati Science and Technology University

Developed a deep learning framework for Bangla vehicle license plate text recognition using image restoration and sequence recognition techniques. The system addresses challenges specific to Bangla character recognition in license plate detection.

Key Contributions:

  • Trained and evaluated 5 distinct deep learning models for Bangla character recognition
  • Collaborated with primary authors on model development and experimentation
  • Contributed to academic writing and manuscript preparation
  • Achieved 96% character-level accuracy on synthetic Bangla license plate dataset
  • Published findings in Springer Communications in Computer and Information Science
