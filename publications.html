Advancing Bangladeshi Intelligent Transportation Systems: An Extended ALPR System with GFPGAN Deblurring and Linguistically Valid Synthetic Datasets

Sagar Mohajan, G.M. Sakhawat Hossain, Md Mynoddin, Rishita Chakma, Tanjim Mahmud, Punam Kanungoe, Auntor Chakma

Lecture Notes in Networks and Systems, Springer, 2022

Automatic License Plate Recognition (ALPR) is a core component of Intelligent Transportation Systems, yet it remains challenging in non-Latin contexts such as Bangladesh. This paper presents an end-to-end Bangla ALPR pipeline that addresses degradation and data scarcity through GFPGAN-based restoration, linguistically constrained synthetic plate generation, and segmentation-free sequence transcription using MobileNetV2 + BiLSTM with CTC decoding.

Key Contributions:

  • Trained and evaluated 5 distinct deep learning models (Custom CNN, InceptionV3, MobileNetV2, VGG16, ResNet50) for Bangla character recognition
  • Collaborated with primary authors on model development, experimentation, and comparative analysis
  • Contributed to academic writing and manuscript preparation

Generative-Enhanced Ensemble Framework for Diabetic Retinopathy Grading under Severe Class Imbalance

Auntor Chakma, Collaborators

Manuscript Completed, 2025

Developed ensemble framework combining VGG19, DenseNet121, and InceptionResNetV2 with GAN-based synthetic data generation and Grad-CAM++ visualization for interpretable diabetic retinopathy grading. Addresses severe class imbalance in medical imaging datasets through advanced data augmentation and ensemble techniques.

Key Contributions:

  • Designed generative AI-enhanced ensemble architecture for handling severe class imbalance
  • Implemented Grad-CAM++ for explainable AI in medical diagnosis
  • Achieved robust performance through weighted ensemble strategies

Attentive TabNet Framework for Multiclass Intrusion Detection in Internet of Medical Things

Auntor Chakma, Co-authors

BSc Thesis, Manuscript in Preparation, 2025

Developed TabNet-based framework with attention mechanisms and GAN-based synthetic data generation for IoMT intrusion detection, achieving 97.96% multiclass accuracy across 89 million network traffic records. Defense completed in May 2025.

Key Contributions:

  • Designed attentive TabNet framework for multiclass intrusion detection in IoMT, overcoming limitations of binary-focused IDS systems
  • Addressed severe data imbalance through GAN-based synthetic minority sample generation
  • Demonstrated TabNet's attention mechanism superiority for generalizable IoMT security models
