A Deep Learning-Based Framework for Bangla Vehicle License Plate Detection and Recognition

Sagor Mohajon, G.M. Sakhawat Hossain, Md Mynoddin, Rishita Chakma, Tanjim Mahmud, Punam Kanungoi, Auntor Chakma

Springer CCIS, vol 2683, 2025

Proposes a deep-learning framework for Bangla vehicle license plate text recognition using image restoration and sequence recognition techniques. The framework achieves 96% character-level accuracy on a synthetic Bangla license plate dataset, demonstrating robust performance for local vehicle identification systems.

Generative-Enhanced Ensemble Framework for Diabetic Retinopathy Grading under Severe Class Imbalance

Auntor Chakma, et al.

Target Journal: Medical Image Analysis / IEEE Journal of Biomedical and Health Informatics

Developed dual-head architecture combining ordinal regression with categorical classification for seven-stage diabetic retinopathy grading, utilizing Stable Diffusion 2.1 generative augmentation with ControlNet-Canny conditioning and morphological attention masks. The framework addresses severe class imbalance challenges in medical imaging through advanced generative techniques. Achieved 91.65% accuracy with 91.67% macro F1-score, validated through Grad-CAM explainability analysis for clinical interpretability.

Attentive TabNet Framework for Multiclass Intrusion Detection in IoMT

Auntor Chakma, et al.

Target Journal: IEEE Internet of Things Journal / Computer Networks

Developed TabNet-based framework with attention mechanisms for multiclass intrusion detection in Internet of Medical Things (IoMT) environments. The framework incorporates GAN-based synthetic data generation to address severe class imbalance in cybersecurity datasets. Achieved 97.96% multiclass accuracy across 89 million network traffic records, demonstrating robust performance for real-world IoMT security applications. The attention-based architecture provides interpretable feature importance for security analysis.
