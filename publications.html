A Deep Learning-Based Framework for Bangla Vehicle License Plate Detection and Recognition

Sagar Mohajan, G.M. Sakhawat Hossain, Md Mynoddin, Rishita Chakma, Tanjim Mahmud, Punam Kanungoe, Auntor Chakma

Communications in Computer and Information Science (CCIS), Vol. 2683, Springer
International Conference on Data Science, AI and Applications (ICDSAIA 2025)
First Online: 02 January 2026, pp 220–235

Bangladesh's rapid increase in automobile traffic has underscored the need for advanced solutions in transportation management, law enforcement, and public security, particularly through automated Number Plate Recognition (NPR) systems. This work presents a comprehensive Bangla number plate recognition system customized to the unique challenges of the Bangla script, which is primarily used in Bangladesh's vehicle registration plates.

Key Highlights:

  • Comprehensive Bangla NPR system addressing unique challenges of Bangla script in vehicle registration plates
  • Custom CNN architecture trained on 2,000 images across 17 classes, augmented to 19,200 images
  • Achieved 96% test accuracy, outperforming InceptionV3 (91.28%), MobileNetV2 (93%), VGG16 (94%), and ResNet50 (71%)
  • Scalable solution for traffic management, automated tolling, and security applications in Bangladesh and regions with similar linguistic challenges

Interpretable Diabetic Retinopathy Classification Using Diffusion-Based Synthetic Images and Explainable Ensemble Method

Auntor Chakma, Collaborators

Manuscript in Preparation, 2025

Developed an interpretable diabetic retinopathy classification system combining diffusion-based synthetic image generation with explainable ensemble methods. The framework addresses severe class imbalance in medical imaging through advanced generative AI techniques while maintaining clinical interpretability.

Key Highlights:

  • Dual-head architecture combining ordinal regression and categorical classification for seven-stage diabetic retinopathy grading
  • Utilizes Stable Diffusion 2.1 generative augmentation with ControlNet-Canny conditioning for addressing severe class imbalance in medical imaging
  • Stacking ensemble of five CNN architectures achieving 91.65% accuracy with 2.09% improvement over baseline models
  • Explainable AI implementation using Grad-CAM++ for clinical interpretability and validation
  • Robust performance with 91.67% macro F1-score demonstrating effectiveness across imbalanced classes

Attentive TabNet Framework for Multiclass Intrusion Detection in Internet of Medical Things

Auntor Chakma, Co-authors

Preprint, Manuscript in Preparation, 2025

Developed an advanced intrusion detection system for Internet of Medical Things (IoMT) environments using TabNet architecture with attention mechanisms. The framework incorporates GAN-based synthetic data generation to address class imbalance challenges in cybersecurity applications.

Key Highlights:

  • Attentive TabNet framework for multiclass intrusion detection overcoming binary-focused IDS limitations in IoMT environments
  • GAN-based synthetic minority sample generation addressing severe data imbalance in cybersecurity datasets
  • TabNet's attention mechanism enabling interpretable feature importance for IoMT security analysis
  • Achieved 97.96% multiclass accuracy across 89 million network traffic records
  • Generalizable security model validated on large-scale real-world IoMT datasets
