A Deep Learning-Based Framework for Bangla Vehicle License Plate Detection and Recognition

Sagar Mohajan, G.M. Sakhawat Hossain, Md Mynoddin, Rishita Chakma, Tanjim Mahmud, Punam Kanungoe, Auntor Chakma

Communications in Computer and Information Science (CCIS), Vol. 2683, Springer
International Conference on Data Science, AI and Applications (ICDSAIA 2025)
First Online: 02 January 2026, pp 220–235

Bangladesh's rapid increase in automobile traffic has underscored the need for advanced solutions in transportation management through automated Number Plate Recognition (NPR) systems. This work presents a comprehensive Bangla number plate recognition system customized to the unique challenges of the Bangla script, which is primarily used in Bangladesh's vehicle registration plates. The proposed system addresses the complexities of the Bangla script using deep learning and image processing techniques.

Key Highlights:

  • Comprehensive Bangla NPR system addressing unique challenges of Bangla script in vehicle registration plates
  • Custom CNN architecture trained on dataset of 2,000 images across 17 classes, augmented to 19,200 images
  • Achieved 96% test accuracy, outperforming InceptionV3 (91.28%), MobileNetV2 (93%), VGG16 (94%), and ResNet50 (71%)
  • Scalable solution for traffic management, automated tolling, and security applications in Bangladesh with potential applicability to regions with similar linguistic challenges

Interpretable Diabetic Retinopathy Classification Using Diffusion-Based Synthetic Images and Explainable Ensemble Method

Auntor Chakma, Collaborators

Manuscript in Preparation, 2025

Developed ensemble framework for interpretable diabetic retinopathy classification utilizing diffusion-based synthetic image generation to address severe class imbalance in medical imaging datasets. The system combines advanced generative AI with explainable ensemble methods for clinical decision support.

Key Highlights:

  • Dual-head architecture combining ordinal regression and categorical classification for seven-stage diabetic retinopathy grading
  • Utilizes Stable Diffusion 2.1 generative augmentation with ControlNet-Canny conditioning for addressing severe class imbalance in medical imaging
  • Stacking ensemble of five CNN architectures achieving 91.65% accuracy with 2.09% improvement over baseline performance
  • Explainable AI implementation using Grad-CAM++ for clinical interpretability and validation of model predictions
  • Robust performance with 91.67% macro F1-score demonstrating effectiveness across imbalanced medical imaging classes

Attentive TabNet Framework for Multiclass Intrusion Detection in Internet of Medical Things

Auntor Chakma, Co-authors

Preprint, Manuscript in Preparation, 2025

Advanced intrusion detection system for Internet of Medical Things (IoMT) environments using TabNet architecture with attention mechanisms. The framework incorporates GAN-based synthetic data generation to address class imbalance challenges in cybersecurity applications, achieving state-of-the-art performance on large-scale network traffic datasets.

Key Highlights:

  • Attentive TabNet framework for multiclass intrusion detection overcoming limitations of binary-focused IDS in IoMT environments
  • GAN-based synthetic minority sample generation addressing severe data imbalance in cybersecurity datasets
  • TabNet's attention mechanism enabling interpretable feature importance for IoMT security applications
  • Achieved 97.96% multiclass accuracy across 89 million network traffic records
  • Generalizable security model validated on large-scale real-world IoMT datasets
