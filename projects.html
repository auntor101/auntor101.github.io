AI Customer Support Chatbot (RAG)

A chatbot that answers customer questions about shipping, returns, payments, accounts, discounts, warranties, and products from a store's own documents, and shows the source of each answer.

Problem. Support staff repeat the same policy answers all day, and a general chatbot can invent a policy that does not exist. Here each answer is retrieved from the store's documents and cited, so a customer or an agent can check it.

How it works. The question is first rewritten using the chat history, then matched against a ChromaDB index built with local all-MiniLM-L6-v2 embeddings. Llama 3 on Groq, the default model, writes the answer from the retrieved passages.

Real-world use. First-line support for a small online shop, leaving staff to handle the cases that need a person. The demo runs on a fictional Bangladeshi store, ShopSmart BD.

No. 02 · Live

VisualMind AI

An app that describes an uploaded image and answers follow-up questions about it.

Problem. A caption alone leaves questions open, and text inside an image is easy to miss. Chaining a captioning model with a vision-language model lets a user ask what is in the image and get the answer in one place.

How it works. BLIP writes a short caption. Llama 4 Scout on Groq then analyses the objects, colors, text, and context, and a chat keeps the image in memory for follow-up questions. The app accepts JPEG, PNG, WebP, and GIF files up to 4 MB.

Real-world use. Drafting alt text for images, reading text in screenshots, and checking what a photo contains. It is also a small working example of a vision-language pipeline.

No. 03 · Live

HireTrack AI

A job-application tracker that scores a resume against a job description, drafts tailored application documents, and follows each application through to an offer.

Problem. Applicants rarely know why automated screening filters out a resume, and tailoring a resume and cover letter for every posting takes time.

How it works. A local scoring engine rates a resume on skills, experience, education, and keywords without any API call, and lists the missing skills. A language model then drafts a tailored resume (PDF and DOCX) and cover letter, and Exa AI finds job listings by semantic search.

Real-world use. A job seeker can check a resume against a posting before applying, and can see which missing skills recur across applications.

No. 04 · GitHub

Anomaly Detection in IoMT Devices

A pipeline that detects and classifies attacks in network traffic from connected medical devices.

Problem. Connected medical devices are targets for network attacks, and attack records are far rarer than normal traffic. The pipeline learns what normal traffic looks like and flags what deviates from it.

How it works. A variational autoencoder trained on about 171,000 normal records and an Isolation Forest each score how unusual a record is. A TabNet classifier takes those scores as extra features and assigns the attack type. The data is a merged WiFi traffic set of about 2.68 million training and 892,000 test records.

Real-world use. The approach applies to a hospital network monitor that flags unusual device traffic.

Status. Research code, not deployed.

No. 05 · GitHub

University Vehicle Tracking

A web platform that shows university vehicles on a live location dashboard, with alerts and role-based access for administrators, drivers, students, and teachers.

Problem. Students and bus drivers lose time on campus transport because nobody outside the vehicle can see where it is.

How it works. Vehicle positions are stored in Firebase Realtime Database and pushed to a React dashboard as they change. Firebase Cloud Messaging sends push notifications, and access is split across five roles (admin, driver, student, teacher, office admin) with Firebase Authentication and JWT.

Real-world use. A university transport office could show students where each bus is and manage the fleet from one dashboard.

Status. A development and learning project.

No. 06 · GitHub

Chittagong Weather Prediction

A classifier that predicts the weather in Chittagong as rain, high temperature, normal temperature, or cold, with a web interface.

Problem. Weather information matters for agriculture, transport, and disaster management. This project builds a small model for Chittagong from local daily records.

How it works. It trains on daily temperature, rainfall, humidity, and sunshine records from a public Mendeley dataset. Median imputation fills gaps, SMOTE balances the classes, and a stacking ensemble of Random Forest, Gradient Boosting, XGBoost, SVM, and Logistic Regression is tuned with randomized search and stratified cross-validation. A Flask app takes the measurements and returns the class with a confidence score.

Real-world use. A small local aid for planning around rain or heat, for example in farming or transport.

Status. A student project, not an operational forecast.
